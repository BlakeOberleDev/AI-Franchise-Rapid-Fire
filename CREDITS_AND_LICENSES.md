# Credits and License Verification

Vanguard Champions is built entirely with original, procedurally generated assets.

- **Artwork:** All unit silhouettes, palettes, tiles, particles, and UI graphics are drawn at runtime with HTML5 Canvas or CSS. No downloaded or externally hotlinked art is used.
- **Audio:** Every effect and music loop is synthesized at runtime with the Web Audio API. No downloaded or externally hotlinked audio is used.
- **Code:** The implementation and original lore are authored for this repository.
- **Fonts:** The interface uses system font stacks only.

Result: no third-party licensed art or audio is required. The repository contains no external asset dependencies.
